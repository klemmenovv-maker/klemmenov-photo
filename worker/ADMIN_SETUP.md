# Запись: кабинет клиента и админка владельца

Что есть в коде (ничего не задеплоено, секретов в репозитории нет):

- `/my/` на сайте: клиент видит свои заявки и статус, может добавить время/заметку или отменить.
  Доступ по личному токену, он хранится только в браузере клиента (в базе лежит SHA-256).
- `/admin/` на сайте: только для владельца, вход через Google. Список заявок, статусы, правка полей,
  заметка для себя, сообщение клиенту, напоминания, график свободности из Google Календаря.
- Worker: `/request` теперь сохраняет заявку в KV (`BOOKINGS`), `/my`, `/admin/*`, cron раз в 5 минут
  шлёт напоминания в Telegram (`reminders.mjs`).

## Что нужно сделать перед включением (по порядку)

1. Google Cloud Console → тот же OAuth-клиент (`GOOGLE_OAUTH_CLIENT_ID`), в «Authorized redirect URIs» добавить
   `https://klemmenov-booking.white-term-cd13.workers.dev/admin/callback`.
2. Секрет сессии: `openssl rand -base64 36 | npx wrangler secret put SESSION_SECRET`
3. Убедиться, что заданы `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
   `OWNER_EMAIL` уже в `wrangler.toml` (vars).
4. `REQUIRE_TERMS`: на сайте пока нет опубликованных условий, поэтому кнопка «Отправить заявку здесь» шлёт
   `accepted_terms: true` только пока условий нет. Чтобы заявки принимались, поставьте `REQUIRE_TERMS = "false"`
   (или опубликуйте условия: тогда на форме появится галочка).
5. `npx wrangler deploy` из `worker/`, затем публикация сайта (GitHub Pages).

## Как это работает

- Клиент отправил заявку → Worker кладёт её в KV и возвращает токен → браузер запоминает → `/my/`.
- Вы: `/admin/` → «Войти через Google». Пускает только `OWNER_EMAIL` с подтверждённой почтой; сессия 30 дней.
- Напоминания в Telegram: ваши (на конкретное время), «клиент не дописал детали» (нет времени через
  `NEEDS_DETAILS_HOURS`, по умолчанию 24 ч), «съёмка в ближайшие 24 часа».
- Хранение: заявки живут 400 дней (персональные данные), у каждой записи свой TTL.

## Ограничения

- Токен клиента привязан к браузеру: другой телефон/браузер увидит пустой список (вход по коду в мессенджер не делали).
- KV без блокировок: рассчитано на одного владельца; одновременные правки с двух вкладок могут затереть друг друга.
- Занятость в графике берётся из публичного `/schedule` (Google Календарь + удержания).
